Что такое агент

Агент — это система с инструкциями, ограничениями и инструментами, которая действует от имени пользователя.

  • Инструкции объясняют, что система должна делать.
  • Ограничения объясняют, чего система не должна делать.
  • Инструменты позволяют системе действовать.

Учебный пример

Если программа может получить данные и выполнить действие по запросу пользователя, это уже не только чат с ответами.
