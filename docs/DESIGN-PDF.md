# Правила оформления PDF

Дата фиксации: 19 октября 2026 года

Это адаптация независимого веб-разбора Mobbin для учебного PDF. Значения из
исходного preview помечены как «Источник»; значения, выбранные для печати,
помечены как «Наше дополнение».

| Правило | Значение | Основание |
|---|---|---|
| Страница | A4, 210 × 297 мм, вертикально | Наше дополнение для PDF |
| Поля | 18 мм с каждой стороны | Наше дополнение; место номера страницы учитывается отдельно |
| Основной шрифт | Локальный Sligoil Micro Regular: `public/fonts/Sligoil-Micro.otf` и `Sligoil-Micro.ttf` (одно начертание, Regular) | Выбрано пользователем вместо Inter; кириллица проверена по cmap обоих файлов |
| Лицензия шрифта | SIL Open Font License 1.1, текст в `public/fonts/OFL` | Файл лицензии из комплекта шрифта |
| Основной текст | 11 pt, межстрочный интервал 1,5 | Наше дополнение для читаемого русского текста |
| Заголовки | 28 / 20 / 14 pt | Наше дополнение; веб-размеры preview не переносятся буквально |
| Фон и основной текст | `#FFFFFF` и `#141414` | Источник: Canvas и Ink |
| Вторичный текст | `#707070`; используем только при достаточной контрастности | Источник: Muted |
| Учебный пример | Поверхность `#F3F3F3` | Источник: Soft Canvas; применение к примеру — наше дополнение |
| Тонкая линия | `#E0E0E0` | Источник: Hairline |
| Поле/мягкая поверхность | `#F0F0F0` | Источник: Field и Soft Hairline |
| Ссылки | Подчёркивание; цвет не единственный признак | Источник: preview описывает underlined links; печатное правило — наше дополнение |
| Синий акцент | `#0066FF` только для заранее определённой учебной пометки | Цвет и ограниченность акцента — источник; новое назначение для учебника — наше дополнение |
| Скругления | Не добавлять декоративные скругления; использовать только для заранее определённых блоков | Источник задаёт 16/24 px и pill для веб-компонентов; ограничение для PDF — наше дополнение |
| Тени | Не использовать | Источник: система не использует drop shadow |
| Переносы | Заголовок не оставлять без начала следующего абзаца; длинный текст переносить, не уменьшать весь документ | Наше дополнение для печати |

## Разрешённые виды поверхностей

В PDF используются белый лист, мягкая серая поверхность учебного примера и
тонкая серая линия. Содержание не передаёт шаблону произвольные цвета, шрифты,
размеры или CSS.

## Проверка шрифта

Тестовая фраза:

> Съешь ещё этих мягких французских булок

19 октября 2026 года локальный `InterVariable.ttf` был проверен через
Fontconfig и HarfBuzz: шрифт распознан как Inter Variable, среди языков есть
`ru`, а для каждого символа тестовой фразы построен собственный глиф. TTF
сохранён рядом с WOFF2 для воспроизводимой локальной проверки и будущей печати.

Официальный источник файлов: [rsms/inter](https://github.com/rsms/inter),
версия `v4.1`; файл лицензии сохранён в проекте отдельно.
