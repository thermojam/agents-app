# Дизайн: реализация PRODUCT-AUDIT.md

Дата: 2026-10-26. Основа: `docs/PRODUCT-AUDIT.md`.

## Решения
- Цель: локальный инструмент для одного человека. Этап 4 (сервер, аутентификация, хостинг) не делаем.
- Бюджет модели: 100 ₽ (`budget.json`). Учитываются все вызовы, включая `/suggest` и `model:check`.
- Незакоммиченные изменения в рабочей копии не трогаем и не коммитим без подтверждения.
- Актуальный JSON документа: `docs/agents-tools/building-agents.json`. `document.json` удалён в рабочей копии.
- Линтер и CI не добавляем. Тесты: встроенный `node --test`.
- Учебные файлы в `docs/` не переносим.

## Этапы
- Этап 0, пайплайн: `agent:check`, фикстуры `terms:check` и `report:check`, `tools:check`, `tool:check` (пропуск при недоступном сервисе), единый учёт бюджета, `npm run check` без вызовов модели и сети.
- Этап 1, документация: README, `.idea/` в `.gitignore` (по подтверждению).
- Этап 2, интерфейс: продуктовые тексты, убрать неработающую форму, состояния ошибок, редактор скрыт в сборке, история `draft.json` (10 копий), кнопка PDF для утверждённой версии.
- Этап 3, тесты: `node --test` для валидации, экранирования и `/api/works`, `suggest.ts` с заглушкой модели; E05/E06 как `scripts/e2e-editor.ts`.
