# Учебный PDF-агент

Локальный инструмент для одного человека. Берёт статью, готовит черновик учебного текста,
даёт его проверить человеку и после утверждения собирает PDF.

Конвейер: статья → проверенный draft → preview → утверждение человека → PDF.

## Установка

Нужны Node.js 22 и `pdftotext` (пакет poppler; на macOS: `brew install poppler`).

```
npm install
npx playwright install chromium
cp .env.example .env
```

В `.env` укажите `LLM_API_KEY`. Файл не попадает в git и не отдаётся в браузер.

## Запуск редактора

```
npm run dev
```

Редактор работает только в dev-режиме. В `npm run build` панели «Работы» нет.

## Конвейер из командной строки

```
npm run source -- "https://openai.com/..." "имя-работы"   # загрузить статью в папку работы
npm run agent -- "https://openai.com/..."    # черновик, проверка и preview
npm run approve -- "ИМЯ_РАБОТЫ"              # утверждение человеком (ручная сверка)
npm run pdf -- "ИМЯ_РАБОТЫ"                  # PDF только для утверждённого текста
```

Работы лежат в `docs/agents-tools/`. Расходы модели пишутся в `usage.jsonl` рядом с работой.
Лимит задан в `docs/agents-tools/budget.json`.

## Проверки

```
npm run check
```

Запускает typecheck и проверки, которые не вызывают модель и не ходят в сеть.
`model:check` и `tool:check` вызывают модель или внешний сервис, поэтому в `check` не входят.
`tool:check` при недоступном сервисе печатает «пропущено» и завершается с кодом 0.
